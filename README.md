## Overview of drhanburyphysics

drhanburyphysics is a collection of web-based physics learning tools aimed at A level and IB students. The resources are built to help learners engage with core topics through interactive activities that fit naturally into lessons, revision time, and guided self-study.

It is a good fit for teachers who need classroom-friendly digital materials and for students who prefer a more active way to revisit physics ideas. Since everything runs in the browser, there is no local install process to manage, which makes it convenient in shared or mixed-device learning settings.
